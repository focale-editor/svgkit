# 📰 SvgKit changelog

## 0.1.0

- Add owned document editing sessions, structural operations, immutable commits,
  mixed-content/text-run editing and namespace-aware imports.
- Add all SVG path commands, exact arc retention, absolute/control-point
  normalization, point lists, transform lists and viewport authoring values.
- Add shape, text, image, symbol, gradient, pattern, clipping, mask, filter and
  marker constructors; all extension elements and attributes remain editable.
- Add inline CSS declaration editing, local reference diagnostics, ID renaming
  and subtree duplication with remapped identifiers.
- Expand the pinned W3C corpus to 94 files and independently validate typed edits
  and a visible authoring scenario with librsvg.

- Initial portable document codec, examples, bounded parsing, and tests.
